# 回归检查清单（重构后）

## 客人侧

1. 首页加载：菜单可见，未开单时可看菜单但不可提交。
2. 首登：无昵称会被引导完善资料；只填昵称可通过。
3. 配送下单：必须选择地址，起送价提示正确。
4. 自取下单：必须填写电话（支付方式仅现金/微信转账）。
5. 地址管理返回结算页：新增/编辑/删除/设默认后结算页自动刷新；从地址簿返回时先显示全页“载入中...”，地址列表一次性更新，不应出现旧地址列表先显示后跳变。
6. 客人改单/取消单：库存释放与按钮状态正常。

## 店主侧（主链路）

1. 开单草稿 -> 开单（`OPEN`）
2. 截单（`OPEN -> CLOSED`）
3. 生产管理：修改 `preparedQty`，首页 `CLOSED` 生产进度同步
4. 交付准备：配送/自取分卡；保存排序不改状态；`备单完成` 进入 `FULFILLING`
5. 配送执行：仅配送单；`🚚/💰` 可切换；点击行进订单详情
6. 自取执行：仅自取单；`OPEN/CLOSED/FULFILLING` 可操作
7. 完成本次开单：仅所有 `ACTIVE` 单已交付且已收款时成功；成功后首页回到“暂无开单中”

## 店主侧（管理）

1. 菜品库：增删改、上架/下架、图片显示正常
2. 订单管理：待确认单确认/拒绝、改单、取消单
3. 客人管理：客人列表、客人详情、历史订单跳转
4. 开单复盘：销售额/订单列表/菜品销量统计正确（仅 `ACTIVE`）
5. 起送价规则：城市规则增删改保存正确

## 正确性（大数据量）

1. 复盘页在 500+ 订单场景不漏单（分页生效）
2. 完成开单校验在 500+ `ACTIVE` 订单场景不误判
3. dashboard 销售额与订单管理口径一致（仅 `ACTIVE`）
